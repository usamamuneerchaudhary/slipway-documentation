## Testing

```bash
composer install
vendor/bin/pest                       # everything
vendor/bin/pest --testsuite=Unit
vendor/bin/pest --testsuite=Conformance
vendor/bin/pest --testsuite=Feature   # Testbench: real artisan commands
vendor/bin/pint --test                # code style
```
