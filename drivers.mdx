---
title: "Drivers"
description: "Enable providers, override the output path, pin GitHub Actions, and merge raw YAML as an escape hatch."
---

```php
'drivers' => [
    'github'    => ['enabled' => true, 'options' => ['permissions' => ['contents' => 'read'], 'pins' => ['actions/checkout' => '<40-char sha>']]],
    'bitbucket' => ['enabled' => true, 'options' => ['image' => 'php:{php}-cli']],
    'gitlab'    => ['enabled' => true, 'path' => '.gitlab-ci.yml', 'raw' => ['default' => ['tags' => ['docker']]]],
    'circleci'  => ['enabled' => true],
],
```

| Driver | Output | Options |
|---|---|---|
| `github` | `.github/workflows/slipway.yml` | `runner`, `permissions`, `pins` |
| `bitbucket` | `bitbucket-pipelines.yml` | `image`, `shell_image`, `bootstrap`, `size` |
| `gitlab` | `.gitlab-ci.yml` | `image`, `shell_image`, `bootstrap`, `tags` |
| `circleci` | `.circleci/config.yml` | `image`, `shell_image`, `bootstrap`, `resource_class`, `context`, `serial_deploys` |

`path` overrides the output file. `raw` is deep-merged into the generated YAML as an escape hatch (maps merge; lists and scalars replace).

## GitHub Actions versions

The `github` driver uses these actions. Each `actions/*` default runs on Node.js 24.

| Action | Default |
|---|---|
| `actions/checkout` | `v7` |
| `actions/cache` | `v6` |
| `actions/setup-node` | `v7` |
| `actions/upload-artifact` | `v7` |
| `actions/download-artifact` | `v8` |
| `shivammathur/setup-php` | `v2` |

Self-hosted runners need Actions Runner 2.327.1 or later for these versions.

Major-version tags are mutable. Run `slipway:pin` and put the SHAs it prints in `pins`. A pin replaces the default for that action, so run `slipway:pin` again when you want a newer default. See [Security model](/security-model).

`setup-node` is given `package-manager-cache: false`. Dependency caching follows the `cache` key only.

See [Provider support](/provider-support) for what each driver can express, and [Writing a driver](/writing-a-driver) to add another provider.
